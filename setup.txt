LOCAL PHP + MYSQL (XAMPP) ENVIRONMENT SETUP:
---------------------------------------------
1. Start Apache & MySQL services in XAMPP Control Panel.
2. Open http://localhost/phpmyadmin/ and create database: library_management_db
3. Import backend/schema.sql into library_management_db.
4. Access app at http://localhost/library-management/

INSTANT NODE.JS RUNNER (NO XAMPP REQUIRED):
-------------------------------------------
1. Run `npm install` in the project root.
2. Run `node server.js`
3. Open http://localhost:3000 in your browser.
4. Default Admin Login: admin@library.com / admin123
5. Default Student Login: student@library.com / student123
